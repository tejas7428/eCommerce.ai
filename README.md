# 🛍️ EcomIntelli

### AI-Powered E-Commerce Recommendation System

> **Discover better. Recommend smarter. Shop personally.**

EcomIntelli is a full-stack AI-powered e-commerce recommendation platform that combines **React, Node.js, MongoDB, Python, FastAPI, and Scikit-learn** to deliver personalized product discovery.

Instead of showing the same products to everyone, EcomIntelli learns from product information and user interactions to generate **personalized and similar-product recommendations**.
